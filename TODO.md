
* map editor
  - rooms defined by json
  - rooms loaded from file
  - click to place tiles
  - wasd to move around the map
  - hl to change the width of the placed tile
  - jk to change the height of the placed tile
  - c to cycle through defined color palette
  - x to set collision
  - : opens command palette
  - :/r sets the name of the tile
  - :/c sets the color of the tile

* movable platforms
  - platforms that move once
  - platforms that move on trigger
* enemies
  - move in a pattern
  - change pattern based on distance to player
  - define in json
* bosses
  - move in a pattern
  - change pattern based on distance to player
  - have phases that change behavior
* sound
  - rooms can change sound properties
  - rooms can add reverb
  - sound can have distance
  - sound can have pitch
  - sound can have volume
